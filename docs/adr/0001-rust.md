# ADR-0001: Implement in Rust

- Status: Accepted (2026-10-02)

## Context
The harness is a developer tool used locally and in CI, invoked at high frequency by agents through the CLI or
MCP, and distributed across platforms.

## Decision
The core, CLI and MCP server are written in Rust. The on-device helper is written in Kotlin because of platform
constraints.

## Rationale
- A single static binary with no runtime dependencies makes installation simple (cargo-dist, Homebrew, curl script).
- Fast startup: in CLI mode every agent call starts a process, so startup time directly affects the experience.
- tokio fits managing many external processes (adb, logcat, Gradle) concurrently.
- The type system suits a stable output contract and error model.
- An official MCP SDK exists (`rmcp`).

## Rejected alternatives
- **TypeScript:** the most mature MCP ecosystem and the lowest contribution barrier, but it needs a Node runtime and
  loses on single-binary distribution and startup time.
- **Go:** equally good distribution and concurrency, but a weaker MCP ecosystem and less expressive types.

## Consequences
- A higher contribution barrier than TypeScript. Mitigated by clear crate boundaries and pure parsers with fixture
  tests, so starter tasks such as "add a parser" are approachable.
- An npm wrapper can be offered later to ease adoption for JS users.
